1. Getting Started / စတင်အသုံးပြုခြင်း

1.1 Create an Account / အကောင့်ဖွင့်ခြင်း

1 Open the app → you'll see the Login page.
2 Click the မှတ်ပုံတင်ရန် (Register) tab.
3 Enter your name, email, and password (min 6 characters).
4 Click မှတ်ပုံတင်ရန် button to create your account.
💡 Tip: If email confirmation is required, check your inbox. Otherwise you'll be auto-logged in.

1.2 Log In / ဝင်ရောက်ခြင်း

1 On the ဝင်ရန် (Login) tab, enter your email and password.
2 Click ဝင်ရန် button.
⚠️ Rate Limiting: Too many wrong attempts? Wait 60 seconds before trying again.

2. Dashboard / ပင်မစာမျက်နှာ

The Dashboard gives you a quick overview of your finances.
ပင်မစာမျက်နှာတွင် သင့်ငွေကြေးအခြေအနေကို အကျဉ်းချုပ်ကြည့်ရှုနိုင်ပါသည်။

2.1 Summary Cards / အကျဉ်းချုပ်ကတ်များ

💰 Total Income / စုစုပေါင်းဝင်ငွေ

Sum of all income transactions / ဝင်ငွေအားလုံး၏ စုစုပေါင်း

📤 Total Expense / စုစုပေါင်းအသုံးစာရင်း

Sum of all expense transactions / အသုံးစာရင်းအားလုံး၏ စုစုပေါင်း

💵 Balance / လက်ကျန်ငွေ

Income minus expense. Green if positive, red if negative.

2.2 Recent Transactions / လတ်တလောမှတ်တမ်းများ

Shows your 5 most recent transactions. Click "View all transactions" to see everything.

သင့်၏ နောက်ဆုံး မှတ်တမ်း ၅ ခုကို ပြသပေးပါသည်။

3. Transactions / ငွေလွှဲမှတ်တမ်း

3.1 Adding a Transaction / မှတ်တမ်းထည့်သွင်းခြင်း

1 Click Add New button (top-right).
2 Select type: Expense or Income.
3 Enter amount (min 1).
4 Choose a category (filtered by type).
5 (Optional) Add a description.
6 Pick the date (defaults to today).
7 Click Add.

3.2 Editing & Deleting / ပြင်ဆင်ခြင်းနှင့် ဖျက်ခြင်း

Hover over any transaction → click ✏️ (edit) or 🗑️ (delete). A confirmation is required for delete.

မှတ်တမ်းပေါ်တွင် mouse တင်လိုက်ပါက ပြင်ဆင်ရန် ✏️ နှင့် ဖျက်ရန် 🗑️ ပေါ်လာပါမည်။

3.3 Filtering / စစ်ထုတ်ခြင်း

FilterDescription
🔍 SearchSearch by description or category name / ဖော်ပြချက် သို့မဟုတ် အမျိုးအစားဖြင့် ရှာဖွေပါ
📂 TypeAll / Income / Expense
🏷️ CategoryFilter by specific category / အမျိုးအစားအလိုက် စစ်ထုတ်ပါ
🔄 ClearClick to reset all filters / စစ်ထုတ်မှုများ ပြန်ဖျက်ရန်

4. Reports / အစီရင်ခံစာများ

4.1 Monthly Bar Chart / လအလိုက် ဘားဇယား

Shows income (green bars) and expense (red bars) for each month. Click the year buttons at top to switch years.

တစ်နှစ်တာ၏ လတိုင်းအတွက် ဝင်ငွေ (အစိမ်း) နှင့် အသုံးစရိတ် (အနီ) ကို ပြသပေးပါသည်။

4.2 Pie Charts / အဝိုင်းပုံဇယားများ

  • Expense by Category: See where your money goes / သင့်ငွေ ဘယ်နေရာတွေမှာ သုံးစွဲခဲ့သလဲ
  • Income by Category: See where your money comes from / သင့်ဝင်ငွေ ဘယ်နေရာတွေက ရရှိခဲ့သလဲ

4.3 Summary Cards / အကျဉ်းချုပ်

Total Income, Total Expense, and Balance displayed at the top.

5. Categories / အမျိုးအစားများ

5.1 Default Categories / မူလအမျိုးအစားများ

TypeDefault Categories
💰 IncomeSalary (လစာ), Freelance, Business (စီးပွားရေး), Investment (ရင်းနှီးမြှုပ်နှံမှု)
📤 ExpenseFood (စားသောက်), Transport (သယ်ယူ), Shopping (စျေးဝယ်), Bills (ဘေလ်များ), Healthcare (ကျန်းမာရေး), Entertainment (ဖျော်ဖြေရေး), Education (ပညာရေး), Other (အခြား)

5.2 Managing Categories / အမျိုးအစားများ စီမံခြင်း

1 Click Add New to create a custom category.
2 Enter name, select type (Expense/Income), pick a color from the palette.
3 Hover over any category to ✏️ edit or 🗑️ delete it.
⚠️ Note: Deleting a category does NOT delete its transactions. They become uncategorized.

အမျိုးအစားတစ်ခုကို ဖျက်လိုက်လျှင် ၎င်းနှင့်ဆက်စပ်သော မှတ်တမ်းများ ပျက်မသွားပါ။

6. Settings / ဆက်တင်များ

6.1 Update Profile / ကိုယ်ရေးအချက်အလက် ပြင်ဆင်ခြင်း

1 Edit your display name in the Profile section.
2 Click Save to update.
💡 Note: Email changes must be done via Supabase Dashboard — not in this app.

6.2 Change Password / စကားဝှက် ပြောင်းလဲခြင်း

1 Enter your new password (min 6 characters).
2 Confirm the new password.
3 Click Change Password.

7. Dark Mode / အမှောင်မုဒ်

Toggle dark mode from the sidebar footer.
ဘေးဘားအောက်ခြေရှိ ခလုတ်ဖြင့် အမှောင်မုဒ်ကို ဖွင့်/ပိတ် ပြုလုပ်နိုင်ပါသည်။

🌙 Dark Mode

Better for night use. Your preference is saved automatically.

ညဘက်အသုံးပြုရန် သင့်တော်ပါသည်။ သင့်ရွေးချယ်မှုကို မှတ်သားထားမည်ဖြစ်ပါသည်။

☀️ Light Mode

Classic look. Default if no preference is set.

မူလအလင်းမုဒ်။ ရွေးချယ်မှုမရှိပါက ဤသည်ကို အသုံးပြုပါမည်။

8. Exporting Data / ဒေတာထုတ်ယူခြင်း

8.1 Export Formats / ထုတ်ယူနိုင်သော ပုံစံများ

FormatFileContents
📄 CSVtransactions_DATE.csvAll transactions + summary rows / မှတ်တမ်းများနှင့် အကျဉ်းချုပ်

8.2 How to Export / ဘယ်လိုထုတ်ယူမလဲ

1 Go to Transactions page.
2 (Optional) Apply filters to export only what you need.
3 Click the Export dropdown button.
4 Choose CSV or Excel format.
💡 Tip: Export respects your current filters — filter by date range, type, or category first!

AI ငွေကြေးအကြံပေး (မကြာမီရရှိမည်) သည် သင့်အသုံးစရိတ်များကို ခွဲခြမ်းစိတ်ဖြာပြီး အကြံပြုချက်များပေးပါမည်။

  • Category overspend warnings / အသုံးများနေသော အမျိုးအစားများကို သတိပေးခြင်း
  • Monthly saving suggestions / လစဉ် ငွေစုနည်းလမ်းများ အကြံပြုခြင်း

10. FAQ / အမေးများသောမေးခွန်းများ

Q: Is my data private? / ကျွန်ုပ်၏ဒေတာ လုံခြုံပါသလား။
A: Yes. Your data is stored in Supabase with Row-Level Security (RLS). Only you can see your transactions. / ဟုတ်ကဲ့။ Supabase RLS ဖြင့် သင့်ဒေတာကို သင်တစ်ဦးတည်းသာ ကြည့်ရှုနိုင်ပါသည်။
Q: Can I use the app offline? / အင်တာနက်မရှိဘဲ သုံးလို့ရပါသလား။
A: The app has a local/in-memory fallback. However, full offline support requires Supabase backend. / လောလောဆယ် Supabase နှင့်ချိတ်ဆက်ထားပြီး ဒေတာကို cloud တွင် သိမ်းဆည်းပါသည်။
Q: How do I recover my password? / စကားဝှက်မေ့သွားလျှင် ဘယ်လိုလုပ်ရမလဲ။
A: Use the "Forgot Password" link on the login page, or contact your system administrator. / ဝင်ရောက်ရန်စာမျက်နှာရှိ "စကားဝှက်မေ့သွားသည်" ကို နှိပ်ပါ။
Q: What currency is supported? / ဘယ်ငွေကြေးကို သုံးထားပါသလဲ။
A: Myanmar Kyat (MMK) with Myanmar number format (e.g., ၅,၀၀၀ ကျပ်). / မြန်မာကျပ်ငွေ (MMK) ကို မြန်မာဂဏန်းဖြင့် ပြသထားပါသည်။
Q: How do I change my email? / အီးမေးလ် ဘယ်လိုပြောင်းရမလဲ။
A: Email changes must be done in the Supabase Dashboard. This app supports display name changes only. / Supabase Dashboard တွင်သာ အီးမေးလ်ပြောင်းလဲနိုင်ပါသည်။ ဤအက်ပ်တွင် အမည်သာ ပြောင်းလဲနိုင်ပါသည်။
Q: Does the app have a mobile version? / မိုဘိုင်းဗားရှင်း ရှိပါသလဲ။
A: The web app is fully responsive and works on mobile browsers. A React Native mobile app is in development. / ဝက်ဘ်အက်ပ်သည် မိုဘိုင်းနှင့် အဆင်ပြေအောင် ဒီဇိုင်းထုတ်ထားပါသည်။ React Native အက်ပ်လည်း ထုတ်လုပ်နေပါသည်။
Q: Can I export my data? / ဒေတာတွေ ထုတ်ယူလို့ရပါသလဲ။
A: Yes! Go to Transactions → Export → choose CSV or Excel format. / ထုတ်ယူလို့ရပါသည်။ ငွေလွှဲမှတ်တမ်းစာမျက်နှာမှ CSV သို့မဟုတ် Excel ဖြင့် ထုတ်ယူနိုင်ပါသည်။

# User Feedback — MM Balance (Income/Expense Tracker)

- **How collected:** Direct chat messages from 3 friends
- **When:** July 13th, 2026

## Raw feedback
1. "I like the simple interface, but I wish I could categorize expenses more quickly without clicking multiple menus."
2. "It works great for my daily tracking, but I need a way to export my data to Excel or Google Sheets for monthly planning."
3. "The UI is clean, but the font size for the total balance is a bit small on my phone screen."

## Themes (what keeps coming up)

- Input Speed: Users want fewer clicks to log recurring daily transactions.
- Data Portability: Users want to retain ownership of their data by exporting it to other formats.
- Mobile Readability: Visual hierarchy needs adjustment to make key metrics (like Total Balance) stand out on smaller devices.

## Top 3 things to fix

- [ ] Shortcut/Quick-Add: Add a "Quick Add" button on the dashboard for the most frequent expense categories.
- [ ] Export Feature: Implement a CSV/Excel export button so users can back up their financial data.

- [ ] Mobile Responsive UI: Increase font weight and size for the total balance display to ensure it is legible at a glance.
